Repository for my assignment submissions for FALL 2025 CSC4753 Artificial Intelligence at Louisiana Tech University. All programs are written in Java

**A2**: trains a small neural 4-3-2 3-layer neural network using provided initial weights and biases, and uses gradient descent and backpropagation to correct error. This is performed across 6 epochs of the full data set.

**A3**: uses the training engine developed in A2 to process the MNIST dataset. A3 classifies images, and has many different modes that the user can select upon the model training across the data.

**Othello**: an object-oriented implementation of the game _Othello_ which has a heuristic-driven AI component that uses mini-max search with alpha-beta pruning to decide the best move to take. There are commands to change the depth that mini-max takes, as well as to toggle alpha-beta pruning.
